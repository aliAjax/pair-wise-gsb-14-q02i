# 油品价格维护

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据默认保存在浏览器localStorage中，方便后续扩展接口、权限、图表或地图能力。

## 批量调价

区域运营接收总部调价清单后，可在「批量调价」页一次粘贴 **站点、油品、挂牌价、生效日期** 四列：

- 格式正确的行进入**待审区**；重复站点油品、挂牌价小数位不对（须两位小数）、生效日早于当天等行进入**异常区**并写明原因。
- 异常行可直接在区内修改后重新校验，通过即并入同一批；仍有异常行时**不能送审**。
- 批次可暂存（含异常区），中断后恢复继续处理。
- 「调价批次」页审批通过后，**整批价格和生效日期冻结**；已通过批次可发起**补录**，补录必须填写原因，新版本保留旧价/旧生效日，可按站点油品查看版本历史。

## 代码组织（导入规则、批次保存、页面分开）

- `src/price/importRules.ts`：导入规则。清单文本解析与逐行校验（列数、油品范围、两位小数、生效日期、批内查重、异常行重新校验），不依赖状态，可单独测试。
- `src/price/store.ts`：批次保存。Pinia store，负责批次/版本的 localStorage 持久化、送审、审批冻结、补录版本与旧值保留、编辑区暂存。
- `src/price/types.ts`：批量调价相关数据模型。
- `src/pages/SinglePrice.vue`：单条调价页（原有逐条录入）。
- `src/pages/BulkPrice.vue`：批量调价页（粘贴解析、待审区/异常区、暂存与送审）。
- `src/pages/BatchManage.vue`：批次管理页（待审、通过冻结、补录入口、版本历史）。
- `src/App.vue`：仅负责三个页签的切换与概览指标。
